# Gerência do projeto E-tecidos — AV1 de GPTI

Artefatos de gestão do projeto E-tecidos. A equipe de GPTI (Grupo J) conduz a gestão. A equipe de PSW (Grupo 10) propõe o escopo funcional e desenvolve o produto. A semana letiva 1 começou em 03/08/2026; a AV1 é na semana 8.

O produto é um protótipo: a loja é fictícia, os dados são fictícios, e pagamento e frete são simulados.
